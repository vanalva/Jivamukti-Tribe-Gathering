Lux Lotus palette (provisional)

This page loads src/css/palette-lux-lotus.css on top of variables.css, so every swatch, mode and component above renders in the Luxembourg 2027 colours. The migrated pages still run the Rome seeds until all eight pass the zero-drift gate; at the edition switch these seeds move into variables.css. Values come from the V3 logo files and the brief's colour story only. No colour guide yet, V5 unsigned: treat every value as a placeholder. Navy #0e123a is the ink (neutral 900), not the core seed, because at lightness 0.21 it cannot head a ramp.
