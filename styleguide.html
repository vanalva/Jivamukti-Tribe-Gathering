flwr · v1.0-alpha · by Flowriter

The Webflow framework for the modern web.

flwr is Flowriter's official framework — OKLCH-derived palettes, fluid clamp() typography, native CSS scroll animations, anchor-positioned components, container queries, three-tier tokens, and one-class theme · density · layout-mode switching. Built to ship through the Flowriter converter with minimum custom embeds.

Token system

Twelve variable collections organized in three tiers: raw Palette seeds, semantic Theme tokens with Light/Dark/Brand modes, and Component tokens for shipped components. Every utility consumes a token — no hard-coded rem or hex.

Palette 5 categories + extensible

flwr ships five palette categories — core (primary brand), alternate (secondary brand), accent (visual highlights / spot color), alert (destructive / errors), neutral (grays). Each is a 9-stop OKLCH-derived ramp from a single seed. Both alternates and accents are extensible — add alternate-2, alternate-3, accent-2, accent-3, etc. following the same pattern. No "secondary / tertiary / quaternary" naming required. Status palettes (success, warning, info, focus) ship separately for semantic state.

Media frames ratio clamp

f-ratio-* answers what shape is this. f-frame answers how does that shape change across screens — the question a project otherwise answers by hand, per component and per breakpoint, until the site has three different hero ratios. A frame declares TWO shapes, --_frame---wide for desktop and --_frame---narrow for mobile; the tablet step is derived as the average of the two, so you never declare it. --_frame---cap is an svh ceiling that stops a portrait frame from pushing the page below the fold, and --_frame---focus picks the focal point — a portrait crop of a landscape photo eats the SIDES, so it is mostly a horizontal decision. Stepped vs. fluid

Same two endpoints. The default steps at 991 and 767; is-fluid interpolates the ratio itself across the whole viewport range, so the frame morphs landscape → square → portrait without a single jump. Ratios are stored as unitless numbers (1.3333, not 4 / 3) precisely so they can be interpolated. Needs tan()/atan2() — Chrome 111+, Safari 15.4+, Firefox 108+.

Card stack 8 directions · deck-riffle cycle

A directional deck of cards. Last DOM child = top of stack. Cards behind peek toward a direction set on the wrap (default top-left — same as Dr. Mush). Click the top card to cycle back; click ANY deeper card to bring it to the top. The top card uses a two-step "wind-up + tuck under" motion (matches Dr. Mush exactly: 300ms ease-in-out wind-up, 500ms cubic-bezier(0.25, 0.8, 0.25, 1) back-slide). Other cards use the same smooth transition to glide forward. runtime.js sets the index inline; CSS :nth-last-child rules are the no-JS fallback.

Tokens: --_component---card-stack--{offset-x, offset-y, scale-step, opacity-step, max-depth, aspect-ratio, z-base, shadow-strength}. Direction modifiers on the wrap: .is-direction-{tl, tr, bl, br, up, down, left, right}. Each modifier sets --_card-stack---direction-{x,y} (-1, 0, or 1) and a matching transform-origin so the scale shrinks AWAY from the peek side.

DEFAULT — is-direction-tl (top-left peek, Dr. Mush style). Click the top card or buttons.

flwr framework — overview

flwr is Flowriter's Webflow framework. OKLCH-derived palettes from brand seeds, fluid clamp() typography, native CSS scroll animations + GSAP/IX3 hooks, anchor-positioned components, three-tier tokens with 12 collections, Theme/Density/Layout mode switching, AI-readable semantic HTML.

Built to ship through the Flowriter converter with minimum custom embeds and maximum Webflow native fidelity. The framework name flwr was chosen for its conciseness and brand resonance with Flowriter.

OKLCH is the color space that powers every palette in flwr — perceptually uniform, hue-stable across lightness changes, and easy to derive ramps from a single seed via relative color syntax.

Scroll-triggered dialog data-flwr-trigger="scroll"

Add data-flwr-trigger="scroll" to any flwr_dialog_wrap. runtime.js calls showModal() when scrollY ≥ data-flwr-scroll-threshold (default 200). Set data-flwr-scroll-once="false" to fire on every threshold cross. Reset programmatically via window.flwr.scrollDialog.reset(dialog). Pattern adapted from Dr. Mush.

When you have a grid or flex of bordered cells, two stacked 1px borders form a 2px gap and each cell's individual rounded corners read as separate shapes — instead of one unified group. f-gap-collapse overlaps adjacent borders into a single shared edge. f-radius-inner-{N} straightens internal corners while keeping the outermost 4 (or 2 in flex) rounded with the parent's f-radius-* via border-radius: inherit.
